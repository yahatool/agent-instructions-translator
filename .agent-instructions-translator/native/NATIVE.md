# エージェントの指示翻訳者

## 目的

人間がAIエージェントが英語版を読み込むことを可能にする一方で、ネイティブ言語でAI命令ファイルを理解し、編集できるVSコード拡張を作成します。

正式な英語ファイルは `AGENTS.md` または `SKILL.md` で、ネイティブ言語バージョンは `NATIVE.md` となります。 拡張は、最初の起動時に翻訳され、管理されたファイルを保存します。

## 必須アクション

- ワークスペース内で `AGENTS.md`、`SKILL.md`、`NATIVE.md` をターゲットとする。
- デフォルトでは、無効にします。 フォルダーが `enabled` を `true` と評価するとき、フォルダーが開いているとき、または関連する設定が変更されたときにのみ、ワークスペースローカル状態ディレクトリを作成します。
- 複数のルートワークスペースでは、フォルダレベルの設定を尊重します。 `enabled: true` のユーザ設定は、フォルダーレベルで上書きされない限り、すべてのオープンフォルダに適用されます。
- 3つの同期モードを提供します。
- `nativeToEnglish`: `NATIVE.md` に基づく `AGENTS.md` または `SKILL.md` を更新します。
- `EnglishToNative`: `AGENTS.md` または `SKILL.md` に基づいて `NATIVE.md` を更新します。
- `bidirectional`: 保存されているファイルに関係なく、他のファイルに変換します。
- VSコード設定で3つの翻訳プロバイダ間で切り替えることができます。
- バンドルされたオフラインArgosはデフォルトとしてランタイムを翻訳します
- 設定可能なDeepL CLI
- VSコード言語モデルAPI(`vscode.lm`)
- マークダウン構造、コードブロック、パス、識別子、コマンド、URL、およびフロントマッターを保存し、自然言語のみを翻訳します。
- YAML frontmatterでは区切り、キー、コロン、インデント、コメント、引用符、バージョン、識別子、URL、パス、プレースホルダーを保持し、`name`や`description`などの自然言語スカラー値だけを翻訳する。
- 保存ループを防ぎ、ファイルペアベースで処理をシリアライズします。
- 二方向モードでは、最後の同期以降、両方の変更が行われた場合、競合を検出し、黙って上書きしないでください。
- 最初の二方向スキャンでは、両方のファイルが既に存在している場合は、同期ベースラインとして、両方のファイルを翻訳し、現在のハッシュを記録します。
- 同期メタデータ、集中ネイティブファイル、および隠しワークスペースローカルフォルダ内のキャッシュを保存します。
- デフォルトでは `AGENTS.md` と `SKILL.md` を通常のプロジェクトの場所に保存し、 `.agent-instructions-translator/native/` の `.agent-instructions-translator/native/` の下の `NATIVE.md` を元のディレクトリ階層に格納します。 オプションとして、レガシーの隠れ家レイアウトと並行して保持します。
- アクティブなファイルとコマンドを翻訳して、ワークスペース全体を同期させるコマンドを提供します。
- 文書の内容や資格情報を記録し、管理可能なエラーを表示しないでください。

## 技術的な制約

- TypeScript と VS コード拡張 API の厳密な設定を使用します。
- 将来の追加を可能にするために小さなインターフェイスの背後にある翻訳プロバイダを配置します。
- アトミックはできるだけ多く書きます。
- 不信なデータとして翻訳されたテキストを扱い、それを実行しません。
- コマンド・ライン引数の代わりに、標準入力でDeepLにボディを渡します。
- ボディをArgosに標準入力で翻訳し、翻訳中にネットワーク通信を実行しません。
- ユーザーが Python、pip、Argos、およびモデルをインストールする必要性を除去するためにOSおよびCPU固有のVSIXとArgosを束ねて下さい。
- ファイル名、ネイティブ言語のロケール、英語のロケール、除外パターン、モデルファミリー、CLIパス、およびCLI引数の構成を許可します。
- 純粋な同期とマッピングロジックのユニットテストを追加し、VSコードの依存関係を最小限に保ちます。
- ポータブル`.agent-instructions-translator/state.json`ベースラインと`.agent-instructions-translator/native/**`ソースファイルをコミットします。 他の翻訳キャッシュ、`.vscode-test`、`node modules`、コンパイル出力、またはシークレットをコミットしないでください。

## 検証

変更を完了する前に、タイプチェックとユニットテストを実行します。 振る舞いが変化したら、片道モード、双方向の衝突処理、ループ防止、およびネストされた `skills/*` の下のファイル名の両方を検証します。
