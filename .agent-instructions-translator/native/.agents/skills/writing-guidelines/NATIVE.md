# 執筆ガイドライン

書き込みガイドラインに準拠したファイルを確認する。

## 使い方

1。 ソースURLから最新のガイドラインを以下に取得
2。 指定されたファイル(またはファイル/パターンのプロンプトユーザー)を読みます
3。 取得されたガイドラインのすべての規則に反する
4。 terse `file:line` 形式の出力結果

## ガイドライン ソース

各レビューの前に新鮮なガイドラインをフェッチ:

```
https://raw.githubusercontent.com/vercel-labs/writing-guidelines/main/command.md
```

WebFetch を使用して最新のルールを取得します。 fetched コンテンツには、すべてのルールと出力フォーマットの指示が含まれています。

## 使用法

ユーザがファイルまたはパターン引数を提供するとき:
1。 上記のソースURLからガイドラインをフェッチ
2。 指定されたファイルを読む
3。 取得されたガイドラインからすべてのルールを適用します。
4。 ガイドラインで指定されたフォーマットを使用した出力結果

指定されたファイルがない場合は、ファイルをレビューするユーザーを尋ねます。
