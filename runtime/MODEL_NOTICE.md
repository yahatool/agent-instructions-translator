# Bundled translation model notice

The Japanese-to-English and English-to-Japanese model packages are downloaded
from the official Argos package index during the platform build:

- `translate-ja_en-1_1.argosmodel`
- `translate-en_ja-1_1.argosmodel`

Their embedded README files credit OPUS-compiled data, Wiktionary/Wiktextract,
CCAligned, WikiMatrix, OpenSubtitles, and pretrained Stanza models.

Argos Translate itself is MIT/CC0 licensed. As of September 2026, the downloaded
model archives do not contain an explicit license file or license metadata.
Redistributors must independently confirm that they have sufficient rights to
redistribute these model packages before publishing a VSIX containing them.
